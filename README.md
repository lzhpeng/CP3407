# JCU Campus Assistant | JCU校园助手

A bilingual chatbot assistant for JCU students, providing information about campus facilities, courses, and services.

## Features | 功能

- Bilingual support (English/Chinese) | 双语支持（英文/中文）
- User registration and login | 用户注册和登录
- Campus information inquiry | 校园信息查询
- Responsive design | 响应式设计

## Usage | 使用方法

1. Register with your JCU student ID and email | 使用JCU学号和邮箱注册
2. Login to your account | 登录您的账号
3. Start chatting with the assistant | 开始与助手对话

## Local Development | 本地开发

Simply open the `index.html` file in your browser to start using the application.

## Security | 安全性

All user data is stored locally in your browser using localStorage.
